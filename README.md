# Email_Scraper
UGA_Domain Email Scraper
UGA Faculty Email Scraper

A Python-based web scraper that extracts faculty email addresses from multiple University of Georgia (UGA) department directory pages.
Because UGA uses a wide range of layouts across colleges, schools, and departments, this scraper uses a robust pattern-based extraction method to reliably detect valid @uga.edu faculty emails from any directory page.

This project is intended for academic, research, and organizational purposes only.
